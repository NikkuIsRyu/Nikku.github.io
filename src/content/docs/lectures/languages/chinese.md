## 🇨🇳 Tonal System & Pinyin

Standard Mandarin features four main tones and one neutral tone:

| Tone | Name | Contour | Mark | Example |
| :--- | :--- | :--- | :--- | :--- |
| **1st** | High level | $55$ | $\bar{a}$ | 妈 (*mā* - mother) |
| **2nd** | Rising | $35$ | $\acute{a}$ | 麻 (*má* - hemp) |
| **3rd** | Dipping | $214$ | $\check{a}$ | 马 (*mǎ* - horse) |
| **4th** | Falling | $51$ | $\grave{a}$ | 骂 (*mà* - scold) |
| **Neutral** | Light | — | $a$ | 吗 (*ma* - question particle) |
