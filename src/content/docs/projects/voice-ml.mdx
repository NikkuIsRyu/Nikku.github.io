Voice ML is my text-to-speech pipeline for Mandarin. I fine-tune [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) voice models on open speech corpora on an RTX 4060. The pipeline then voices the [18 multi-speaker dialogues and 560 vocabulary words](/lectures/languages/chinese/) in my Chinese course notes.

## How it works

1. **Data:** Clean single-speaker recordings with transcripts, sliced into short clips and normalised.
2. **Fine-tuning:** Both halves of GPT-SoVITS are trained: the GPT model (what to say, prosody) and the SoVITS model (how it sounds).
3. **Evaluation gate:** A fixed set of test sentences is synthesised and transcribed with Whisper large-v3. A checkpoint only replaces the previous one if its character error rate holds up.
4. **Synthesis:** A batch client renders dialogues with several speakers at normal and study speed, with word-level timestamps for the dialogue player.

[Source code on GitHub ↗](https://github.com/NikkuIsRyu/Voice_ML_Project)
